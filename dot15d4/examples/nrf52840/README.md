# dot15d4 Examples for nRF52840

The following commands assume that the nRF52840 examples directory is your
current working directory:

```sh
cd examples/nrf52840
```

The examples are grouped by topic, one folder per topic under `src/bin`, each
with its own README:

- [`src/bin/radio`](src/bin/radio/README.md) — radio driver tests and
  calibration (`dot15d4-driver` focused).
- [`src/bin/timer`](src/bin/timer/README.md) — high-precision timer driver
  tests (`dot15d4-driver` focused).
- [`src/bin/tsch`](src/bin/tsch/README.md) — a TSCH node that can be
  configured into the different roles of a TSCH network.
